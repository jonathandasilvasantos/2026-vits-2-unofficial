## ✅ SOLUÇÃO DEFINITIVA: R1 GRADIENT PENALTY

R1 penalty age na CAUSA: previne o discriminador de criar
scores extremos que causam gradientes explodindo.

### Implementação para train.py:

No loop de treino do discriminador, APÓS calcular disc_loss:

```python
# ===== R1 GRADIENT PENALTY =====
# Aplicar APENAS no audio real (não no fake)
if step % 16 == 0:  # A cada 16 steps para economizar GPU
    y_real = y.detach().requires_grad_(True)
    
    # Forward pass com real audio
    mpd_real, _, _ = mpd(y_real)
    msd_real, _, _ = msd(y_real)
    
    # Calcular gradientes do discriminador em relação ao input
    all_real_scores = []
    for scores in mpd_real:
        all_real_scores.append(scores[-1])  # último layer
    for scores in msd_real:
        all_real_scores.append(scores[-1])
    
    r1_grads = torch.autograd.grad(
        outputs=[s.sum() for s in all_real_scores],
        inputs=y_real,
        create_graph=True
    )[0]
    
    r1_penalty = r1_grads.pow(2).flatten(1).sum(1).mean()
    disc_loss_total = disc_loss_total + 10.0 * r1_penalty
# ===== FIM R1 =====
```

### Versão ainda mais simples:

```python
if step % 16 == 0:
    y_real = y.detach().requires_grad_(True)
    # Usar apenas MSD (mais simples)
    d_real, _, _ = msd(y_real)
    pred = d_real[-1][-1]  # output do último discriminador
    r1_grad = torch.autograd.grad(
        pred.sum(), y_real, create_graph=True
    )[0]
    r1_penalty = r1_grad.pow(2).mean() * 10.0
    disc_loss_total += r1_penalty
```

### Parâmetros:
- Peso: 10.0 (padrão para R1, reduzir para 1.0 se disc não aprende)
- Frequência: a cada 16 steps (como StyleGAN2) para economizar GPU
- NOTA: requires_grad_(True) no input + create_graph=True são essenciais
