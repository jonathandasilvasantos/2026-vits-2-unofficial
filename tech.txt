[ARCHITECTURE OVERVIEW - Following paper strictly]

VITS2 = VAE + Normalizing Flows + Adversarial Training + HiFi-GAN decoder

Key improvements over VITS:
  1. Stochastic Duration Predictor with adversarial learning (replaces flow-based SDP)
  2. Monotonic Alignment Search with Gaussian noise
  3. Normalizing Flows with Transformer Block (captures long-term dependencies)
  4. Speaker-Conditioned Text Encoder (multi-speaker, not used for LJSpeech)
  5. No blank token interspersion (unlike VITS)
  6. Mel-spectrogram as posterior encoder input (not linear spectrogram)


[MODULE 1: TEXT ENCODER]
Architecture: Transformer encoder with relative positional representation
Layers: 6
Attention heads: 2
Hidden dimension: 192
FFN filter channels: 768
FFN kernel size: 3 (1D convolution-based, not linear)
Dropout: 0.1
Input: IPA phoneme sequences (NO blank tokens, unlike VITS)
Output: h_text (hidden representation), mu_theta, sigma_theta (prior parameters)
Phonemizer: open-source IPA converter (phonemizer library)
Note for LJSpeech: single speaker, no speaker conditioning on text encoder


[MODULE 2: POSTERIOR ENCODER]
Architecture: Non-causal WaveNet residual blocks
Input: 80-band mel-spectrogram (VITS2 change: uses mel, not linear spec)
WaveNet layers: 16
Hidden channels: 192
Kernel size: 5
Dilation rate: 1
Output: mu_q, log_sigma_q (approximate posterior q(z|x_mel))
Latent channels: 192


[MODULE 3: NORMALIZING FLOWS WITH TRANSFORMER BLOCK]
Number of affine coupling layers: 4
WaveNet residual blocks per coupling layer: 4
Hidden channels: 192
Kernel size: 5
Dilation rate: 1
Volume-preserving (shift-only, no scale)
VITS2 addition: Small transformer block with residual connection added into flows
  Purpose: Capture long-term dependencies when transforming distribution
  Position: Added between convolution blocks in each coupling layer
Direction: Forward (posterior z -> transformed z) during training
           Inverse (prior z -> latent z) during inference


[MODULE 4: DECODER (HiFi-GAN V1 Generator)]
Input channels: 192
Upsample initial channel: 512
Upsample rates: [8, 8, 2, 2] (total 256x = hop_length)
Upsample kernel sizes: [16, 16, 4, 4]
ResBlock type: 1 (ResBlock1)
ResBlock kernel sizes: [3, 7, 11]
ResBlock dilation sizes: [[1,3,5], [1,3,5], [1,3,5]]
Multi-Receptive Field Fusion: sum of parallel residual block outputs
Channel progression: 192->512->256->128->64->32->1
Final conv bias: removed (mixed precision stability)


[MODULE 5: DISCRIMINATOR]
Multi-Period Discriminator (MPD): 5 sub-discriminators, periods [2, 3, 5, 7, 11]
Multi-Scale Discriminator (MSD): 1 sub-discriminator (raw waveform only)
Total: 6 sub-discriminators
Activation: LeakyReLU (slope=0.1)
MPD: weight normalization, 2D convolutions
MSD: spectral normalization, 1D grouped convolutions


[MODULE 6: STOCHASTIC DURATION PREDICTOR (VITS2 version)]
VITS2 replaces flow-based SDP with adversarial learning approach
Generator G: Takes h_text and Gaussian noise z_d as input, predicts duration
Discriminator D: Time step-wise conditional discriminator
  Input: h_text and either real duration d (from MAS) or predicted d_hat
  Operates per-token (handles variable length)
Losses:
  L_adv(D) = E[(D(d, h_text) - 1)^2 + (D(G(z_d, h_text), h_text))^2]
  L_adv(G) = E[(D(G(z_d, h_text), h_text) - 1)^2]
  L_mse = MSE(G(z_d, h_text), d)
Training: Separately trained as last step (30k steps), reduces overall computation


[MODULE 7: MONOTONIC ALIGNMENT SEARCH WITH GAUSSIAN NOISE]
Base: Dynamic programming algorithm from Glow-TTS
Q[i,j] = max(Q[i-1,j-1], Q[i,j-1]) + P[i,j] + epsilon
P[i,j] = log N(z_j; mu_i, sigma_i)
epsilon = noise from N(0,1) * std(P) * noise_scale
noise_scale: starts at 0.01, decreases by 2e-6 per step
Noise only at beginning of training (helps explore better alignments)
Implementation: Cython on CPU


[AUDIO PROCESSING]
Sampling rate: 22050 Hz
FFT size: 1024
Window size: 1024
Hop length: 256
Mel channels: 80
Mel f_min: 0.0
Mel f_max: None (Nyquist)
Reconstruction loss uses 80-band mel-spectrogram
Posterior encoder input: 80-band mel-spectrogram (VITS2 change)


[TRAINING HYPERPARAMETERS - Per paper]
Optimizer: AdamW
  beta1: 0.8
  beta2: 0.99
  weight_decay: 0.01
Learning rate: 2e-4 (initial)
LR decay: 0.999^(1/8) per epoch
Batch size: 256 instances per step (paper states this, adapt for single GPU)
  Single RTX 3090 Ti: likely batch_size ~32-48 with gradient accumulation
Mixed precision: Yes (fp16)
Windowed generator training: segment_size = 32 frames = 8192 audio samples
Main network training: up to 800k steps
Duration predictor training: 30k steps (separate, last step)


[TRAINING LOSSES]
L_total = L_recon + L_kl + L_dur + L_adv(G) + L_fm(G)

L_recon: L1 mel-spectrogram reconstruction loss (weight c_mel = 45)
L_kl: KL divergence between posterior and flow-enhanced prior (weight c_kl = 1.0)
L_dur: Duration predictor losses (adversarial + MSE, trained separately)
L_adv(G): Least-squares GAN generator loss (all 6 sub-discriminators)
L_adv(D): Least-squares GAN discriminator loss
L_fm: Feature matching loss (weight lambda_fm = 2)


[INFERENCE PARAMETERS]
noise_scale (prior): 0.667
noise_scale_w (duration): 0.8

  - WaveNet residual blocks, 16 layers, hidden=192, kernel=5, dilation=1
  - VITS2 change: input is 80-band mel-spectrogram
  - Gated activation (tanh * sigmoid), weight normalization
  - Reparameterization trick for sampling z
  - Output: z, mu_q, log_sigma_q, mask

Module 3: Normalizing Flows with Transformer Block (src/models/flows.py)
  - 4 affine coupling layers with channel flip
  - 4 WaveNet blocks per coupling layer
  - Volume-preserving (shift only, log-det-Jacobian = 0)
  - VITS2 addition: FlowTransformerBlock with residual connection
    Small transformer (2 heads, LayerNorm, scaled dot-product attention)
    Captures long-term dependencies per paper Section 2.3
  - Forward/inverse verified: z_rec == z (atol=1e-4)

Module 4: HiFi-GAN Decoder (src/models/decoder.py)
  - Upsample rates [8,8,2,2], kernels [16,16,4,4]
  - Initial channel 512, channel halving per stage
  - ResBlock1 with kernels [3,7,11], dilations [[1,3,5]x3]
  - Multi-Receptive Field Fusion (sum of parallel ResBlocks)
  - No bias on final conv (mixed precision stability)
  - Output: tanh bounded [-1, 1]

Module 5: Discriminator (src/models/discriminator.py)
  - Multi-Period Discriminator: 5 sub-discs, periods [2,3,5,7,11]
    2D convolutions, weight normalization
  - Multi-Scale Discriminator: 1 sub-disc (raw waveform, VITS modification)
    1D grouped convolutions, spectral normalization
  - Total: 6 sub-discriminators
  - Returns per-discriminator outputs + feature maps for L_fm

Module 6: MAS with Gaussian Noise (src/models/mas.py)
  - Dynamic programming (forward + backward traceback)
  - VITS2: Gaussian noise on Q values
    epsilon = N(0,1) * std(P) * noise_scale
  - MASNoiseScheduler: initial=0.01, decay=2e-6/step
  - Verified: monotonic, covers all mel frames, correct shape
  - Pure Python/NumPy (Cython upgrade possible for speed)

Module 7: Stochastic Duration Predictor (src/models/duration_predictor.py)
  - Generator: Conv1d layers, LayerNorm, ReLU
    Input: h_text (detached) + Gaussian noise z_d
    Output: predicted log-duration
  - Duration Discriminator: Time step-wise conditional
    Input: duration (real/fake) + h_text (detached)
    Per-token discrimination score
    LeakyReLU activation
  - Losses: LSGAN adversarial + MSE
  - Trained separately (30k steps per paper)

Module 8: Full VITS2 Model (src/models/vits2.py)
  - SynthesizerTrn class assembles all modules
  - Training forward: text + mel -> all intermediate outputs for losses

Transformer Block Position Fix (advices.txt - MEDIUM PRIORITY):
  File: src/models/flows.py, src/models/posterior_encoder.py
  
  Problem: FlowTransformerBlock was applied AFTER all WaveNet layers
  in each coupling layer. Paper Section 2.3 says "between the
  WaveNet residual blocks."
  
  Fix: Modified WaveNetResBlock.forward() to accept optional
  mid_block and mid_position parameters. The transformer is now
  inserted at the midpoint of WaveNet layers (position = n_layers // 2).
  With 4 WaveNet layers (0,1,2,3), transformer runs after layer 1
  and before layer 2, placing it exactly between the WaveNet blocks.
  
  This preserves the residual pathway correctly - the transformer
  operates on the hidden state x flowing between WaveNet layers,
  not on the skip connection output.
  
  PosteriorEncoder is unaffected (no transformer, mid_block=None).
  
  Tests: 137/137 passed after fix.
